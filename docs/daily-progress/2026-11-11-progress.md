### 8.4 Problems found (for Person A)

1. **Default vector mode (`QDRANT_PATH`) cannot store new vectors in the running API.**
   `POST /api/embeddings/generate` → "SQLite objects created in a thread can only be used
   in that same thread" (local Qdrant uses SQLite; FastAPI runs the route on a worker
   thread). Vectors only appear because the startup code re-embeds all stored articles on
   the main thread, and it hides errors (`except Exception: pass` in `app/main.py`). The
   Qdrant server mode works. Unit tests pass because they run on one thread.
2. **The model cannot be downloaded on a fresh machine.** `_load_model` sets
   `HF_HUB_OFFLINE=1` before both attempts, so the "first-time download" fallback is also
   offline. Worked only by starting with `HF_HUB_OFFLINE=0`.
3. **`alembic upgrade head` fails on PostgreSQL:** revision id
   `0002_remaining_tables_and_constraints` (37 characters) does not fit
   `alembic_version.version_num` (32). PostgreSQL rolls back, leaving 0 tables.
4. **Reuters feed URL** (`reutersagency.com/feed/...`) returns HTTP 404.
5. Quality: same-event articles labelled RELATED; one mis-grouped article; weak topics.
